## 2D Game Engine

Babylon.js 2D (`@babylonjs/2d`) is a dedicated package for building complete 2D games — from side-scrollers to isometric RPGs and turn-based strategy. It leverages the Babylon.js `Engine` for GPU-accelerated rendering, textures, and audio while providing its own scene graph, camera, physics, and input systems designed specifically for 2D.
